# 个人安全实验环境搭建清单

## 一、总体原则

三条底线，任何情况下都不应突破：

1. **实验网络与生产/家庭网络隔离**，不与办公网、NAS、智能家居同层；
2. **所有实验在快照保护下进行**，随时可回滚；
3. **不使用他人的真实系统练习**，靶场与自建环境足以覆盖绝大多数知识点。

## 二、虚拟化方案选型

| 方案 | 优势 | 局限 |
| --- | --- | --- |
| VMware Workstation | 快照/克隆成熟，兼容性好，网络模式丰富 | 商业授权 |
| VirtualBox | 免费开源 | 性能与稳定性略逊 |
| Hyper-V | Windows 原生，可开机即用 | 与 VMware 存在兼容冲突 |
| Proxmox VE | 服务化，适合长期维护多台机器 | 需独立主机，学习成本偏高 |
| Docker | 启动快，适合单服务靶场 | 不适合完整系统级渗透练习 |

个人推荐：**VMware Workstation 或 VirtualBox + 独立 Host-Only 网段**。若已有闲置机器，Proxmox 的长期体验最好。

## 三、网络设计

```
[ 宿主机 ]
   ├─ VMnet8 (NAT)     → 攻击机出网更新
   ├─ VMnet1 (Host-Only 192.168.56.0/24) → 攻击机 ↔ 靶机 内网
   └─ 禁用桥接，避免靶机直接暴露到家庭局域网
```

**务必禁用桥接模式（Bridged）**：桥接会让靶机直接获得局域网 IP，一旦靶机被攻陷或存在蠕虫类程序，会波及家庭网络中的其他设备。

## 四、核心虚拟机清单

| 角色 | 推荐系统 | 说明 |
| --- | --- | --- |
| 攻击机 | Kali Linux | 工具齐全，滚动更新 |
| 备用攻击机 | Parrot OS / Ubuntu | 避免单一环境依赖 |
| Windows 靶机 | Windows 10/11 或 Server 2019 | 练习域渗透与免杀对抗 |
| Linux 靶机 | Ubuntu / CentOS | 练习提权与 Web 漏洞 |
| 域环境 | DC + 2 台成员机 | 练习域内信息收集与横向 |

域环境至少需要 **1 台域控 + 2 台成员机**，否则大量横向手法无法复现。

## 五、靶场资源

| 类型 | 资源 | 特点 |
| --- | --- | --- |
| 在线靶场 | 各类 Web 漏洞练习平台 | 免搭建，适合入门 |
| 镜像靶机 | VulnHub、HackTheBox 离线镜像 | 完整机器，贴近真实 |
| 漏洞应用 | DVWA、Pikachu、Juice Shop、WebGoat | 单应用，聚焦 Web 漏洞 |
| 云安全 | 云靶场（IAM、容器逃逸） | 需关注费用与授权 |
| 内网靶场 | 自行搭建域环境 | 最有价值，也最费时间 |

**建议路径**：Web 应用靶场 → 单机靶机（VulnHub）→ 自建域环境 → 云环境。

## 六、快照与备份策略

- **基线快照**：系统装好、工具配齐后打一次，命名如 `BASE-clean`；
- **按任务快照**：每次开始新练习前打一次，避免上一题残留影响判断；
- **快照命名规范**：`<用途>-<日期>`，如 `DC-20260901`，否则半年后完全分不清；
- 快照占用磁盘空间可观，定期清理，磁盘预留空间建议 ≥ 剩余 40%。

## 七、宿主机侧的准备

1. **关闭宿主机的危险服务**：SMBv1、不必要的共享、远程桌面（如非必需）；
2. **杀软排除项**：把实验目录加入白名单，避免工具被误删（也便于观察真实环境中的查杀行为差异）；
3. **资源分配**：内存有限时优先保证攻击机与域控，其余靶机可减配；SSD 对多虚拟机并发的体验提升最明显；
4. **网络监控**：可在虚拟网段挂一个抓包虚拟机或使用宿主机抓包，便于分析实验过程中的流量。

## 八、学习记录习惯

每完成一个靶机或漏洞练习，记录四件事：

1. 信息收集阶段遗漏了什么；
2. 哪一步卡住、为什么卡住；
3. 最终的攻击链如何串联；
4. 从防御视角该如何检测这一链路。

这四条记录下来，比多做十个靶机更有价值。

## 小结

实验环境的核心价值是**让你可以安全地犯错**。投资在隔离与快照上的时间，会在第一次误操作时全部赚回来。
