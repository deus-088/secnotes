# 思维导图渲染验证

这篇笔记是测试夹具，用来验证思维导图的渲染链路。
缩进决定层级，`-` 前缀可省略；一级分支自动左右平分。

```mindmap
渗透测试流程
  信息收集
    被动收集
    主动扫描
  漏洞验证
    手工验证
    PoC 复现
  后渗透
    权限维持
    横向移动
```

上图之后仍有正文，用来确认渲染没有吞掉后续内容。

## 单节点边界

只有一行时退化为单个节点，不画连线：

```mindmap
只有一个节点
```

## 空内容回退

语言标记写了但内容为空时，应当回退成普通代码块而不是空白：

```mindmap

```
