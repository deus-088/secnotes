# 数据库基础


## 一、数据库基础——增删改查
```bash
中文	英文  	SQL语句	         作用

增	Create	INSERT	   新增一行或多行数据

查	Read	SELECT  	查询数据

改	Update	UPDATE	      修改已有数据

删	Delete	DELETE	      删除已有数据
```

### 1.1.增 INSERT
例1：向数据库增加30岁的张三：
```sql
INSERT INTO users (name, age)
VALUES ('张三', 30);
```
也可以一次增加多项：
```sql
INSERT INTO users (name, age)
VALUES ('赵六', 28), ('钱七', 35);
```

### 1.2. 查 SELECT
#### 1.2.1查询表所有数据：
```sql
SELECT * FROM users;
（查询用户表所有数据）
```
#### 1.2.2查询表指定列：
```sql
SELECT name, age FROM users;
（查询用户表表中指定的姓名与年龄列）
```
#### 1.2.3带条件的查询：
```sql
SELECT * FROM users WHERE age > 25;
（查询用户表中年龄大于25岁的）
```
#### 1.2.4排序与分页：
```sql
SELECT * FROM users
ORDER BY age DESC
LIMIT 10;
```

### 1.3. 改 UPDATE
#### 1.3.1 修改数据
SET指出要改动的数据，WHERE指出改动哪里的数据：
```sql
UPDATE users
SET age = 21
WHERE name = '张三';
把姓名name为“张三”的那条记录，年龄age改成21
```
#### 1.3.2 WHERE条件注意事项
如果不加WHERE，会把整张表所有用户的年龄都改成21（如下）。所以UPDATE和DELETE一定要先确认WHERE条件。
```sql
UPDATE users SET age = 21;
```

### 1.4 删 DELETE
#### 1.4.1 删除数据
```sql
DELETE FROM users
WHERE id = 3;
删除id=3的那条数据
```
```sql
DELETE FROM users;
删除整张表的数据（但表结构仍存在
```

```
容易混淆的点
DELETE、TRUNCATE、DROP 的区别
    语句	                            作用	            是否可回滚	       表结构
  DELETE FROM  users WHERE ...	删除部分或全部行	  通常可以              	保留
  TRUNCATE TABLE users           	快速清空整张表	  通常不可回滚    保留
  DROP TABLE users	        删除整张表	  通常不可回滚	        删除
```
